# 🎮 Ashes of the Moon Fortress

بازی کامل 2D اکشن پلتفرمر با سیستم RPG، همراه هوشمند، مبارزه و داستان

## 📦 دانلود پروژه

### روش ۱: دانلود از طریق مرورگر (توصیه می‌شود)

1. پروژه را اجرا کنید:
   ```bash
   npm run dev
   ```

2. در مرورگر به آدرس `http://localhost:3000` بروید

3. روی دکمه **"📦 Download Full Project (ZIP)"** در گوشه بالا-راست صفحه کلیک کنید

4. فایل `ashes-of-the-moon-fortress.zip` به صورت خودکار دانلود می‌شود

### روش ۲: صفحه دانلود مستقل

1. پروژه را اجرا کنید:
   ```bash
   npm run dev
   ```

2. در مرورگر به آدرس `http://localhost:3000/download.html` بروید

3. روی دکمه دانلود کلیک کنید

### روش ۳: ساخت ZIP با اسکریپت

```bash
# نصب archiver (اگر نصب نیست)
npm install archiver

# اجرای اسکریپت
node create-zip.js
```

## 🚀 شروع سریع

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# باز کردن در مرورگر
# http://localhost:3000
```

## 🎮 کنترل‌ها

| کلید | عملکرد |
|------|---------|
| ← → | حرکت چپ/راست |
| ↑ | پرش |
| Space | حمله شمشیر |
| F | گلوله آتشین مارا |
| E | تعامل (NPC، چک‌پوینت، خروج) |
| U | منوی ارتقا |
| ESC | مکث |
| R | شروع مجدد (بعد از مرگ) |

**موبایل:** کنترل‌های لمسی به صورت خودکار ظاهر می‌شوند

## 🏰 مراحل بازی

### ۱. روستای خاکستر (Ashen Village)
- آموزش بازی
- آشنایی با مارا
- دشمنان پایه
- اولین چک‌پوینت

### ۲. جنگل زمزمه (Whispering Forest)
- مسیرهای مخفی
- گیاهان نفرین شده
- **انتخاب داستانی مهم**
- مینی‌باس

### ۳. معدن متروکه (Abandoned Mine)
- پلتفرم‌های متحرک
- تیغ‌های خطرناک
- کلید و درهای قفل
- Shrine ارتقا

### ۴. قطار سوزان (Burning Train)
- مرحله متحرک
- موانع سقوطی
- ارواح آتش
- مینی‌باس سریع

### ۵. قلعه ماه (Moon Fortress)
- منطقه نهایی
- دشمنان نخبه
- **باس نهایی سه فازی**
- پایان‌های متعدد

## 🎭 پایان‌ها

### پایان قهرمانانه (Heroic)
آردن ارواح را آزاد می‌کند و به همراه مارا به طلوع خورشید می‌رود

### پایان فداکاری (Sacrifice)
آردن خود را فدا می‌کند تا ارواح آزاد شوند

### پایان فاسد (Corrupted)
آردن قدرت تاریک را جذب می‌کند و به حاکم جدید تبدیل می‌شود

## ⚙️ ویژگی‌های فنی

- **Phaser 3** - موتور بازی
- **TypeScript** - کد تایپ‌سیف
