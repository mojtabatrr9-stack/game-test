# ساخت APK

این پروژه برای تبدیل نسخه وب به APK با Capacitor آماده شده است.

## ساخت آنلاین با GitHub Actions

1. کل محتویات پروژه را در یک repository گیت‌هاب آپلود کنید.
2. به تب **Actions** بروید.
3. workflow با نام **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید (یا یک commit جدید push کنید).
5. بعد از موفقیت build، در صفحه اجرای workflow بخش **Artifacts** فایل `Ashes-of-the-Moon-Fortress-APK` را دانلود کنید.

فایل APK از نوع debug است و برای نصب و تست روی گوشی مناسب است.
